# discord-jellyfin-webhook-templates
A few templates for webhooks and jellyfin
## How to use
To use this plugin you need to have the jellyfin webhook plugin [installed](https://github.com/jellyfin/jellyfin-plugin-webhook)

1. Select 'Discord Destination'
2. Select one of the appropriate notification type
   - Item Added
   - Item Deleted
     - In Item Type, make sure that Movies, Season, Series, and Albums are checked
3. Import the discord webhook url
4. Done
